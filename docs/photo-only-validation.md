# v0.7.2 写真保存への統一

- 全体画像・切り抜き画像とも「写真に保存」に統一。プレビューは共有メニューと画像の長押しによる保存、および「戻る」だけに整理した。
- ファイル保存のボタン、保存先の分岐、`downloadPng` を削除。共有非対応・キャンセル・エラー時もダウンロード経路はない。
- エンコード済みPNGから共有する仕組みと、長押し可能な画像プレビューは維持。iPhoneで共有メニューの「画像を保存」を選ぶ必要がある点は同じ。
- 旧ダウンロードを使っていたE2Eは、写真保存のプレビューからPNGを読み取り、全画素一致、切り抜き寸法と色、不透明な背景合成を検査する方式へ変更。
- 写真保存テストでは、ファイル保存ボタンがないこと、共有非対応時も長押しの案内と画像が残ること、小画面で「戻る」に到達できることを確認する。

## ガイド・互換性

Modern Web Guidanceを `share image files`、`Web Share API` で検索したが、対応するガイドはなかったため取得・適用していない。前回参照したMDN・WebKit公式資料に基づく共有APIの機能検出とユーザー操作直後の呼び出しを維持した。新しいWeb API・依存パッケージは追加していない。

iPhone実機のOSメニューと「写真」への追加は未検証。ブラウザテストでは共有APIをスタブし、実際のPNGとUIを検証している。
